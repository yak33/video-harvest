独创轻量 MSE 缓冲微播方案。无需点击进入，鼠标移入缩略图 160ms 即刻静音流畅动起来；离开即刻销毁播放器，绝对零资源泄漏。

Canvas 现场抓帧与多级封面

针对 Twitter/X 等动态卸载 DOM 封面的单页流媒体，直接通过 Canvas 对当前正在播放的视频画面现场精准截帧，100% 还原真实视频封面。

主动 DOM 探测与流重载引导

刷新按钮不再是简单的重绘视图。一键主动向当前网页注入探测器扫描直链；如发现已被清空的 Blob 流，智能提供重载网页一键恢复捕获。

01

获取代码与构建

克隆仓库并使用原生 Node.js 进行单命令打包：

git clone https://github.com/yak33/video-harvest.git
cd video-harvest
node build.mjs
02

载入浏览器扩展

Chrome / Chromium：访问 chrome://extensions 开启开发者模式，点击「加载已解压的扩展程序」，选择 dist/chrome 文件夹。

Firefox：访问 about:debugging，选择 dist/firefox/manifest.json 临时载入。

03

打开网页尽情收割

在任意网页播放视频，点击右上角 VideoHarvest 扩展图标，即可自由预览清晰度、悬停看画面，并一键高速下载！

常见问题解答

解开您关心的每一个疑问

为什么 VideoHarvest 坚持零 NPM 运行时生产依赖？ +
现代浏览器扩展追求极高的稳定性、安全合规性与即时响应。零外部打包器使得项目源码清晰可审计，审查打包时毫秒级完成，杜绝臃肿的 node_modules 带来的供应链安全风险。
为什么部分视频下载后其他工具只有画面没有声音，而 VideoHarvest 有？ +
很多流媒体（如 Twitter/X 及各大流媒体站）的 1080p 高清视频将音频和视频切片分离存放。普通插件如果只抓取了视频流，下载出来的文件就会缺少音频轨。VideoHarvest 在解析 Master 清单时自动识别关联音频，并在下载时通过 Mux 引擎自动将音轨与画轨完美合并输出为完整的 MP4 文件。
遇到部分页面播放后没有检测到视频怎么办？ +
您可以点击弹窗左下角的【刷新】按钮，插件将主动注入脚本扫描当前网页 DOM 中的所有视频直链；若网络流此前被清空，还可根据引导一键重新加载当前网页重新捕获。此外，您也可以使用顶部的自定义解析栏直接粘贴链接进行解析。
