Privacy Policy

隐私权政策

Effective Date: October 17, 2026 · Version: 1.0 生效日期：2026年10月17日 · 版本：1.0
Summary / Zero Data Collection
VideoHarvest does NOT collect, store, transmit, or monetize any personal information, browsing history, or user downloads. All network detection, HLS/DASH media parsing, AES-128 decryption, and audio-video remuxing are performed 100% locally on your computer inside the browser sandbox.

1. Information Collection and Use

VideoHarvest is a developer tool and productivity browser extension designed to help users detect, preview, and save web streaming media directly to their local devices.

No Data Collected: We do not operate any tracking servers or data analytics backends. We do not collect user IP addresses, device identifiers, cookies, keystrokes, or visited web addresses.

  • No External Transmission: The extension operates self-contained without connecting to third-party tracking or cloud sync servers.
  • No Analytics or Ads: There are no advertising SDKs, tracking pixels, or telemetry frameworks embedded in VideoHarvest.
  • Pure Client-Side Processing: Media stream demuxing and transmuxing (MPEG-TS/fMP4 into MP4) are computed entirely on the client side via browser standard APIs.

2. Permission Usage and Justification

The extension requests only the minimum permissions necessary to fulfill its core functionality. Below are the specific justifications for each permission declared in manifest.json:

Permission Justification & Purpose
webRequest Used locally to inspect response headers and media manifest URLs (m3u8 and mpd) so the extension can display available video resolutions. No web traffic is recorded or sent externally.
downloads Invokes the browser's native download API to save the merged MP4 video file to the user's local disk upon user request.
storage Saves user preferences (such as concurrent segment download threads and filename naming templates) locally in chrome.storage.local.
tabs Associates detected media streams with the current browser tab to ensure the popup displays media detected on the active webpage only.
scripting Extracts video thumbnails, captures live preview frames from playing videos, and performs local DOM inspection when user clicks refresh.
offscreen Manifest V3 standard: Runs the audio-video transmuxer and creates local media blobs in an isolated sandbox document without blocking the UI.
Host Permissions Required to fetch audio/video fragments hosted across diverse CDN domains strictly based on the user's download action.

3. Data Security and Encryption

Since all operations execute locally on your device, your data never leaves your computer. For encrypted HLS media (AES-128), decryption keys are fetched directly by your browser from the authorized origin and decrypted in local memory, after which the key is discarded immediately.

4. Third-Party Websites

When downloading media, your browser communicates directly with the respective third-party hosting server. Those third-party websites have their own privacy policies. VideoHarvest has no control over and assumes no responsibility for third-party practices.

5. Contact Us

If you have questions or concerns regarding this Privacy Policy, please reach out via GitHub Issues:
https://github.com/yak33/video-harvest

核心隐私承诺 / 零数据收集
VideoHarvest 绝不收集、不存储、不分享、不传输任何用户的个人身份信息（PII）、浏览历史或下载内容。
所有网络请求嗅探、切片下载、AES-128 解密及音视频封装均在您本机的浏览器沙盒内完成，100% 离线本地运行。

1. 信息收集与使用

VideoHarvest 是一款专注于帮助用户嗅探、预览和备份合法网页音视频的本地工具扩展。

零数据收集： 本扩展没有搭建任何用于追踪或收集用户数据的后端服务器，不收集 IP 地址、设备信息、Cookie 或网页浏览历史。

  • 无远程服务器回传： 本扩展在浏览器沙盒内完全自包含运行，不向任何第三方云端上报数据；
  • 无第三方追踪分析： 本扩展不包含任何分析统计代码（如 Google Analytics 等）或广告营销脚本；
  • 纯本地执行： 视频切片合并（MPEG-TS/fMP4 Remuxing）完全依靠本地浏览器标准 API 完成。

2. 浏览器权限用途声明

本扩展在 manifest.json 中声明的各项权限仅用于支撑核心功能：

权限 用途说明
webRequest 在浏览器本地监听网络响应头与 MIME 类型，以捕获视频清单（m3u8、mpd 等）。绝不向外转发网络数据。
downloads 调用浏览器原生下载管理器，将合并好的视频文件保存到用户的本地硬盘中。
storage 仅用于在用户的浏览器本地保存用户的设置选项（如下载分片并发数、文件名模板）。
tabs 将捕获的流媒体与具体标签页关联，确保弹窗仅展示当前网页的媒体。
scripting 在用户主动打开弹窗或点击刷新时，提取视频海报或执行现场 Canvas 抓帧。
offscreen Chrome MV3 官方标准机制：在本地离屏沙盒中生成视频 Blob 数据，彻底避免在后台常驻占用系统资源。

3. 数据安全

由于本扩展不收集或在网络上传输您的任何数据，因此您的数据始终安全地保留在您自己的计算机设备中。对于加密的 HLS 视频流（AES-128），密钥由您的浏览器直接从目标站点获取，并在本地内存解密后立即销毁。
