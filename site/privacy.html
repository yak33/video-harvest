隐私权政策 / Privacy Policy

生效日期 / Effective Date: 2026-10-17 · 版本 / Version: 1.0
核心隐私承诺 / TL;DR Summary
VideoHarvest 绝不收集、不存储、不分享、不传输任何用户的个人身份信息（PII）、浏览历史或下载内容。
所有网络请求嗅探、切片下载、AES-128 解密及音视频封装均在您本机的浏览器沙盒内完成，100% 离线本地运行。

1. 信息收集与使用 / Information Collection and Use

VideoHarvest（以下简称“本扩展”）是一款专注于帮助用户备份合法网页音视频的本地工具扩展。

No Data Collected: We do not collect any user data, personal information, IP addresses, browsing histories, downloaded files, or keystrokes.

  • 无远程服务器回传： 本扩展没有搭建任何用于追踪或收集用户数据的后端服务器；
  • 无第三方追踪分析： 本扩展不包含 Google Analytics、Sentry 或任何第三方营销与广告跟踪代码；
  • 纯本地执行： 视频切片合并（MPEG-TS/fMP4 Remuxing）完全依靠浏览器内置的 MediaSource 及 WebAssembly/本地 JavaScript 在前端沙盒完成。

2. 浏览器权限用途声明 / Permission Usage

为了实现音视频嗅探与下载功能，本扩展在 manifest.json 中声明了以下权限，各项权限的具体使用场景如下：

权限 (Permission) 用途说明 (Justification & Purpose)
webRequest 在浏览器本地监听网络响应头与 MIME 类型，以捕获视频清单（如 m3u8、mpd 等）。绝不向外转发网络数据。
downloads 调用浏览器原生下载管理器，将合并好的视频文件保存到用户的本地硬盘中。
storage 仅用于在用户的浏览器本地（chrome.storage.local）保存用户的设置选项（如下载分片并发数、文件名模板）。
scripting / activeTab 当用户主动点击扩展图标或刷新按钮时，在当前页面抓取视频海报封面帧或执行 DOM 直链探测。不运行任何未受信任的远程代码。
offscreen Chrome MV3 官方标准机制：在本地离屏沙盒中生成视频 Blob 数据，彻底避免在后台常驻占用系统资源。

3. 数据安全 / Data Security

由于本扩展不收集或在网络上传输您的任何数据，因此您的数据始终安全地保留在您自己的计算机设备中。对于加密的 HLS 视频流（AES-128），密钥由您的浏览器直接从目标站点获取，并在本地内存解密后立即销毁。

4. 第三方服务与链接 / Third-Party Services

本扩展可能会从您正在浏览的第三方视频托管网站下载公开的音视频切片。请注意，这些第三方网站拥有其独立的隐私权政策。我们建议您查看所访问网站的隐私权政策与服务条款。

5. 隐私政策的更新 / Changes to This Privacy Policy

我们可能会适时更新本隐私权政策。任何变更都将在本页面上发布最新版本。建议您定期查阅以了解最新信息。
